ENTREGA: JAFFLE SHOP - PAGOS POR METODO Y ESTADO

1. Leer EJERCICIO_PAGOS.md: decisiones de modelado, relaciones, actualizacion
   y alcance de los importes. El modelo principal es:
   models/marts/payments_by_method_and_status.sql

2. Requisitos: Python 3.13 o superior y acceso a Internet para instalar paquetes.
   Descomprimir el ZIP y abrir PowerShell dentro de la carpeta jaffle_shop.

3. Preparar y ejecutar:
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\dbt.exe build --profiles-dir .

4. Verificar las actualizaciones y consultar la documentacion:
   .\.venv\Scripts\python.exe scripts\verify_payment_refresh.py
   .\.venv\Scripts\dbt.exe docs generate --profiles-dir .
   .\.venv\Scripts\dbt.exe docs serve --profiles-dir .

5. Actualizacion periodica (mientras el proceso este abierto):
   .\scripts\refresh_payments.ps1 -Continuous -IntervalSeconds 60
   Ctrl+C para detener. Una ejecucion sin -Continuous actualiza una sola vez.
   No hay ninguna tarea programada instalada. La fuente de este taller son
   los CSV de seeds; deben recibir los cambios antes de recargarlos.

CONTENIDO
- Proyecto dbt con modelos, seeds y configuracion de DuckDB.
- Documentacion de relaciones, columnas y estrategia de reconstruccion.
- Tests de calidad y comprobacion funcional de actualizaciones.
- evidencias/: resultado CSV, resumen y registros de la validacion realizada.

El entorno virtual, la base de datos, .git, logs y target se excluyen del ZIP.
Se generan localmente al instalar y ejecutar el proyecto.
